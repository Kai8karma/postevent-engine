# Orchestrator

**Local pipeline**: `python3 orchestrator/run_pipeline.py [--offline] [--modules m1,m2,m3,m4] [--out OUT] [--event-dir DIR] [--event-tag TAG]` chains M1 enrich -> M2 comms -> M3 repurpose -> M4 dashboard (`seed`->`sync`->`analyze`->`render`) via subprocess. **Live by default** -- every stage calls its real backend (HubSpot, Clay, OpenRouter, Sarvam) unless `--offline` replays fixtures instead, zero network. `--modules` runs a subset in order (e.g. `--modules m1,m4` to skip M2/M3, useful for a fixture with no transcript). Prints a stage/seconds/key-output/pass-fail receipt table, exits nonzero on any stage failure. Also: `--gen-visuals`/`--live-visuals` (M3 image generation), `--no-publish` (skip the Drive-publish stage), `--transcribe-live` (real Sarvam STT instead of a dry run) -- see `--help` for the full flag list. `watch_folder.sh` re-runs it automatically whenever `data/incoming/registrants.csv` changes (fswatch if installed, else a 10s mtime poll).

**n8n: three JSON sets, one shipped.**

- `n8n/railway/` -- the real orchestrator: self-hosted n8n on Railway, one workflow per module (`m1-lead-enrichment.json`, `m2-post-event-comms.json`, `m3-content-repurposing.json`, `m4-lead-intelligence.json`) calling the module API (`api/server.py`) for every HubSpot/Clay/OpenRouter/Sarvam/Drive step, plus a Wait-node approval gate on M2. This is the shipped path -- see `n8n/railway/README.md` for import steps, env vars, and how to trigger each workflow.
- `n8n/local-demo/` -- the same DAG as Execute Command nodes shelling to the CLI scripts, importable into a no-account local n8n (`docker run -it --rm -p 5678:5678 n8nio/n8n`) for a walkthrough with no credentials. Every workflow name flags itself as local-only, not the production design, and carries a Sticky Note explaining that Execute Command is self-hosted-only.
- `n8n/cloud/` -- the original n8n Cloud trial workflow from the first build; that trial instance has since expired (404, gone). Kept in the repo for reference only -- not importable anywhere today without standing up a new Cloud trial.
